# Analyze OpenCanbox E2E Logs

**NEVER read raw `dump_*.log` files directly into context.** Use the CLI analysis scripts:

## 1. Automated Triage (<1,500 tokens)
```bash
./tools/triage_canbox_log.py <dump_file.log>
```
Detects state oscillation/flip-flops, spurious commands vs OEM, bus flooding, and payload length mismatches.

## 2. Byte-Level Differential Analysis
```bash
# Preset mode:
./tools/diff_canbox_frames.py <dump_file.log> --preset <radar|swc|hvac|doors|trip|tpms|alerts|bsi_config|radio>

# Explicit CAN IDs (-c) and Hiworld CMD hex (-p):
./tools/diff_canbox_frames.py <dump_file.log> -c 1D0 1E3 0F6 -p 31

# Full command summary (-s) or compressed export:
./tools/diff_canbox_frames.py <dump_file.log> -s
```
